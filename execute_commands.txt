GUÍA DE COMANDOS - SISTEMA DE MATRÍCULAS (ENTREGA FINAL)
=========================================================

1. SISTEMA REAL (Docker Desktop o terminal, desde la raíz del repositorio)
   docker compose down
   docker compose up --build -d
   docker compose ps
   curl http://localhost:8000/health        # API + PostgreSQL
   (la telemetría queda en datos/telemetry_log.csv)

2. SIMULACIÓN (un comando)
   pip install -r requirements-simulacion.txt
   python simulacion/main.py

3. ANÁLISIS Y FIGURAS
   python analisis/contrast_analysis.py     # M/M/c vs SimPy + Ley de Little
   python analisis/generate_charts.py       # docs/figuras/*.png
   python analisis/tablas.py                # simulacion/resultados/tablas.md

4. RECALIBRAR CON SU PROPIO DOCKER (opcional)
   python datos/generar_carga.py calibrar --n 3000
   python simulacion/calibrar.py
